# Shaheer Hasan Khan — Portfolio

A sleek, responsive personal portfolio built with React + Vite. The design is an original composition inspired by contemporary developer portfolios, with a dark editorial aesthetic, animated hero, project cards, experience timeline, theme toggle and responsive mobile navigation.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit `src/main.jsx` for content and `src/styles.css` for visual styling. The resume is available at `public/Shaheer_Khan_Resume.pdf`.
